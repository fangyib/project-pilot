# Project Pilot 范围与术语

## 定位

Project Pilot 是面向软件项目的工作台。它把一个想法拆成不同能力和产物类型的任务，按用户随时可改的偏好、地区、隐私、预算和已有 API 为每个任务推荐模型，在隔离工作区中执行，并展示运行、变更、验证和集成结果。

它不是公司操作系统，不提供部门、组织树或长期员工档案。

## MVP 边界

第一版必须能完成：

- 不注册 API Key 也能生成项目蓝图和任务拆分。
- 账户、项目、任务三级模型偏好，文案明确“可随时修改”，覆盖顺序为单任务 > 项目 > 账户。
- 一个统一执行器，外加 OpenAI-compatible 适配层。本地试用不调用外部模型。
- 能力任务、接口契约、隔离目录、有限并行和集成。
- 任务详情中的摘要、记录、变更和验证。

第一版不做：多租户企业权限、自定义 Agent 市场、无限供应商自动接入、跨项目长期记忆、手机端完整编辑。

## 术语

| 术语 | 含义 |
| --- | --- |
| Project | 一次软件想法的交付容器 |
| Milestone | 由任务完成情况推导的阶段 |
| Task | 一项能力明确、边界明确的工作，不是永久 Agent |
| Capability | 规划、架构、编码、视觉素材、审查、测试、集成等标签 |
| TaskContract | 并行任务共享的路径、接口和资源规格 |
| Run | 一次执行，包含模型、工具、日志、费用和状态 |
| ChangeSet | 一次 Run 产生的文件变更 |
| Verification | 命令、通过与否和证据 |
| Decision | 需要用户选择的确认项 |
| Artifact | 文档、素材、页面或预览等产物 |
| ModelConnection | 加密保存的供应商连接，界面只显示 Key 后四位 |
| ModelPreference | 可随时修改的推荐偏好 |
| ModelProfile | 带更新日期的模型能力档案 |
| ModelRecommendation | 主推荐、备选、过滤原因和预计成本 |
| Executor | 本产品自己的运行器，负责工具、日志和隔离，不是模型 |
| Provider Adapter | 把统一工具协议转换成某一供应商 API 的适配层 |
