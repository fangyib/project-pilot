# Project Pilot

面向软件项目的 AI 工作台。描述一个想法后，系统会拆分任务、推荐模型，并在隔离目录中执行、集成和验证。

注册和生成蓝图不需要 API Key。模型偏好可以随时修改，覆盖顺序是：单个任务 > 项目 > 账户默认。

## 运行

```powershell
npm install
npm test
npm run dev
```

打开 http://127.0.0.1:3210 。
